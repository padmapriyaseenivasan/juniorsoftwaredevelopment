SYSTEM REQUIREMENTS SPECIFICATION
Software Requirements The software requirements define the technology stack needed to run the application efficiently. This project follows the WAMP/XAMPP (Windows/Linux, Apache, MySQL, PHP) model, which is the industry standard for small-to-medium web applications. • Operating System: Windows 10/11, Linux (Ubuntu/CentOS), or macOS. PHP is cross-platform, allowing the system to be hosted on various environments. • Web Server: Apache HTTP Server. This serves as the bridge between the browser requests and the PHP engine. • Back-end Language: PHP 8.x. Using the latest version of PHP ensures better security, faster execution speeds, and access to modern functions like typed properties. • Database: MySQL 8.0. This relational database is used to store structured data such as customer profiles, order IDs, garment types (shirts, trousers, silks), and payment logs. • Front-end Technologies: * HTML5 & CSS3: For the structural layout and styling of the dashboard. o JavaScript/jQuery: To handle client-side form validation (e.g., ensuring a phone number is 10 digits before submission) and asynchronous data loading for a smoother user experience. o Bootstrap 5: A CSS framework used to make the laundry portal responsive, ensuring it looks professional on both desktop monitors and tablets used at the shop counter. • Web Browser: Any modern browser such as Google Chrome, Mozilla Firefox, or Microsoft Edge. • Development Tools: Visual Studio Code or Sublime Text for coding, and phpMyAdmin for graphical database management. 4.2 Hardware Requirements The hardware requirements for a PHP-based Laundry Management System are modest, as the heavy processing is handled by the server, and the client-side only needs to render HTML. Server-Side Requirements (Minimum): • Processor: Dual-core processor (2.0 GHz or higher). • RAM: 4 GB minimum (8 GB recommended if hosting the database and web server on the same machine). • Hard Disk: 20 GB of available space. While the PHP scripts are small, the database grows as more customer transactions and high-resolution garment images (if any) are added. • Network: Standard Ethernet or Wi-Fi for local network access within the laundry facility. Client-Side Requirements (User/Admin Device): • Processor: Basic Intel Core i3 or equivalent. • RAM: 2 GB. • Display: 1024x768 resolution or higher to properly view the administrative tables and reports. • Peripherals: A thermal receipt printer (for generating laundry tags and customer bills) and a standard keyboard/mouse setup. 4.3 About Software (PHP & MySQL Architecture) The core of this system is built on PHP (Hypertext Preprocessor), a server-side scripting language specifically designed for web development. In a Laundry Management System, PHP acts as the "brain" of the operation. When an admin enters a new order, the PHP script receives the data, processes the business logic (such as calculating the total price based on service type), and communicates with the MySQL database to store the record. Why PHP? PHP is an interpreted language, meaning code is executed on the server and the result is sent to the client as plain HTML. This is ideal for a laundry business because the business logic—such as pricing rules, discount algorithms, and employee permissions—remains hidden from the end-user, ensuring security. Furthermore, PHP’s tight integration with MySQL makes it incredibly fast at handling "CRUD" (Create, Read, Update, Delete) operations, which are the backbone of order management. The Role of MySQL MySQL handles the data persistence. It uses a relational structure where different tables (e.g., Customers, Orders, Services) are linked via primary and foreign keys. For example, when a customer brings in five shirts for dry cleaning, MySQL stores the customer details once and links multiple order entries to that specific user ID. This prevents data redundancy and ensures that if a customer changes their phone number, it only needs to be updated in one place. System Workflow The software operates on a request-response cycle.
